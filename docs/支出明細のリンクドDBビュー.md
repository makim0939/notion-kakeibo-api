# 支出明細のリンクドDBビュー

明細を表ブロックで描くとページが縦に伸びて読みにくいので、
サマリページのテンプレートに置いた**支出DBのリンクドDBビュー**に任せている。
カテゴリごとに色分けされ、折りたためて、高さも抑えられる。

役割分担は以下のとおり。

| 設定 | どこで |
|---|---|
| グルーピング（カテゴリ） | テンプレート |
| ソート（金額の降順） | テンプレート |
| 列の「計算」＝合計 | テンプレート（**API から設定できない**） |
| 該当月だけに絞るフィルタ | コード（`views.update`） |

Notion のテンプレート機能では「その月だけ」という条件を作れないため、
そこだけを毎回の更新で `views.update` に `filter` を送って埋めている。
`filter` 以外は送らないので、テンプレートで作り込んだ表示設定はそのまま残る。

ビューは `ページの child_database ブロック → 支出データソースのビュー一覧から親DBが一致するもの`
という順で特定する。表と円グラフのように複数置かれている場合はまとめて絞る。

なお**円グラフ（ドーナツ）のビューも API から作成できる**が、
無料プランはワークスペースで1つまでなので採用していない。
